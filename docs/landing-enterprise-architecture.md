# Landing Page Enterprise Architecture

## Stack Frontend Utama
- Next.js + TypeScript
- React TS
- Bootstrap 5.3.6
- Axios / Fetch
- Framer Motion
- GSAP

## Arsitektur
Frontend (Next.js / React / Vue / Angular)  
↓  
API Gateway  
↓  
Backend Services (Laravel / Django / .NET / Node / Spring / dll)  
↓  
Database + Cache + Realtime

## Struktur Target
```text
/frontend
  /nextjs-landing
  /react-module
  /vue-module
  /angular-module
  /shared-ui

/backend
  /laravel13
  /django
  /dotnet8
  /nodejs
  /springboot

/gateway
  /nginx

/database
  /mysql
  /redis
  /mongodb
```

## Integrasi API
- REST
- JSON
- JWT
- OAuth
- WebSocket

## Fitur Landing (Wajib)
- Hero cinematic dengan video background
- About (company, vision, story)
- Services (film, video, documentary, commercial, editing, color grading)
- Portfolio (grid, slider, video preview, modal)
- Team
- Timeline / Workflow
- Clients (logo slider)
- Testimonials (carousel)
- Contact (ajax form, map, whatsapp, email)
- Footer (social, copyright)
